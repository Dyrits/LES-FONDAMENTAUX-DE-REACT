# LES-FONDAMENTAUX-DE-REACT

## About The Project

An educational project on the fundamentals of React ("les fondamentaux de React"), built with TypeScript and Vite.

### Built With

- React 18
- TypeScript
- Vite

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

```sh
npm install
```

### Running

```sh
npm run dev
```
